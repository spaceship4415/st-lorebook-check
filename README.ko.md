# 로어북 점검 사용 가이드

[English](README.md)

로어북 엔트리를 켜 놨는데 실제로는 프롬프트에 안 들어가는 경우를 찾아 주는 확장입니다.
모든 로어북을 훑어서 **프리셋에 빠진 아웃렛, 꺼진 마커, 절대 발동하지 않는 설정**을 한 화면에 보여 줘요.
버튼은 모두 휴대폰에서 누르기 좋은 크기로 만들었습니다.

---

## 1. 설치하기

1. 실리태번 위쪽의 **확장 프로그램**(퍼즐 모양 아이콘)을 누릅니다.
2. **Install Extension**을 누릅니다.
3. 이 저장소 주소를 붙여 넣고 **Install**을 누릅니다.

설치가 끝나면 입력창 왼쪽 **마법봉 메뉴**에 **로어북 점검**이 생깁니다.
`/lorebookcheck` 명령으로도 열 수 있어요.

---

## 2. 점검 결과

점검 창 맨 위에는 지금 Chat Completion 프리셋 이름과 요약(예: `켜진 엔트리 15개 중 8개가 프롬프트에 들어가지 않습니다`)이 나옵니다.
**지금 채팅에 걸린 로어북만**을 체크하면 전역·캐릭터·채팅·페르소나에 걸린 로어북만 봅니다.
채팅방 안에서 열면 처음부터 체크된 상태로 열려요.

| 묶음 | 뜻 |
| --- | --- |
| 로어북에만 있는 아웃렛 | 위치가 아웃렛인데 프리셋에 `{{outlet::이름}}`이 없어서 발동해도 버려짐. 매크로 알약을 누르면 복사되니 프리셋 프롬프트에 붙여 넣으면 됨. 대소문자·공백만 다른 매크로가 있으면 알려 줌 |
| 출구 꺼짐 | 엔트리 위치에 맞는 출구가 닫혀 있음 (아래 표) |
| 발동 안 됨 | 설정 때문에 절대 들어가지 않음 (아래 표) |
| 프리셋에만 있는 아웃렛 | 프리셋에 `{{outlet::이름}}`은 있는데 그 이름의 켜진 엔트리가 없어 빈칸으로 들어감. **이 이름으로 엔트리 만들기**로 로어북을 골라 상시(🔵) 엔트리를 바로 만들 수 있음 |
| 참고 | 작가 노트 빈도가 2 이상이라 ↑AN/↓AN 엔트리가 그 턴에만 들어감 |
| 연결된 아웃렛 | 정상 (접혀 있음) |

### 출구 꺼짐

| 위치 | 막히는 경우 |
| --- | --- |
| 아웃렛 | `{{outlet::이름}}`이 꺼진 프롬프트에만 있음 |
| ↑Char / ↓Char | 프리셋의 World Info (before) / (after) 마커가 꺼짐 |
| ↑EM / ↓EM | 예시 대화 마커가 꺼졌거나, 고급 서식의 **예시 대화 안 넣기**가 켜짐 |
| ↑AN / ↓AN | 이 채팅의 작가 노트 빈도가 0 |

### 발동 안 됨

| 이유 | 설명 |
| --- | --- |
| 키 없음 | 상시(🔵)가 아닌데 키가 비어 있음. `@@activate`나 벡터로 켜지는 엔트리는 제외 |
| 내용 없음 | 내용이 비어 있음 |
| 확률 0% | 확률 사용이 켜져 있고 0% |
| 정규식 오류 | `/…/` 모양인데 정규식으로 읽히지 않아 글자 그대로 찾음. 깨진 키를 같이 보여 줌 |
| 아웃렛 이름 없음 | 위치가 아웃렛인데 이름이 비어 있음 |

엔트리마다 로어북 이름, 위치, 걸린 곳(전역·캐릭터 이름 등)이 붙어 있고,
✏️ 버튼을 누르면 로어북 편집기가 열리면서 그 엔트리를 찾아 표시합니다.

---

## 3. 참고

- 프리셋 점검은 **Chat Completion** 프리셋 기준입니다. 다른 API를 쓰고 있으면 창에 안내가 나옵니다.
- 이 확장은 로어북·프리셋·채팅을 **읽기만** 합니다. 직접 **엔트리 만들기**를 눌렀을 때만 고른 로어북에 엔트리를 하나 추가해요.
- 확장 자체 설정이나 데이터는 저장하지 않아서, 지우면 남는 데이터가 없습니다.
